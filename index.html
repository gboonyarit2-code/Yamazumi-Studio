Using the new workspace

Use Work Data to edit. Charts and Operator Load have their own pages. The left navigation can be collapsed. Core columns are shown first; use the row detail button or All columns for advanced fields.

On Charts, choose an Operator, chart style, Fit width or Fit all. Display periods only repeats the view. On Operator Load, switch between per-piece and per-period values. Neither filter changes the underlying calculation.

Save Project writes a .yamproj file. Appearance preferences are stored separately in this browser. Unsaved work is not automatically restored when the browser is closed.
